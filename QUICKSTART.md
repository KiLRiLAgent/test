# 🚀 Быстрый старт

## Установка

```bash
# 1. Клонируйте репозиторий
git clone <repo-url>
cd social-comment-generator

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Настройте конфигурацию
cp .env.example .env
# Отредактируйте .env файл
```

## Демо (без API ключей)

Попробуйте систему с примерами:

```bash
python quickstart.py
```

Это покажет:
- ✓ Анализ структуры комментариев (Step 2)
- ✓ Детекцию AI vs Human
- ✓ Рекомендации по генерации

## Основные сценарии использования

### 1. Анализ существующих комментариев

```bash

python src/analyzer.py
```

Результат:
- Структурный анализ комментариев
- Выделение паттернов успешных комментариев
- Рекомендации для генерации

```bash

python src/parser.py
```

Это создаст тестовые данные для экспериментов.

### 3. Парсинг LinkedIn

```bash

# PLATFORM=linkedin
# LINKEDIN_EMAIL=your_email
# LINKEDIN_PASSWORD=your_password

python src/parser.py
```

⚠️ **Важно**: Используйте осторожно, LinkedIn может заблокировать за частые запросы.

### 4. Полный пайплайн

```bash

```

Это выполнит:
1. Парсинг последних 50 постов
2. Выбор топ-3 комментариев по engagement
3. **Анализ структуры (Step 2)** - главный этап
4. Детекцию AI vs Human
5. (Опционально) Генерацию новых комментариев

### 5. Генерация комментариев

```bash
# В .env добавьте API ключ:
# ANTHROPIC_API_KEY=sk-...

# OPENAI_API_KEY=sk-...

python src/generator.py
```

## Step 2: Анализ структуры комментариев

Это **ключевой этап** системы, который разбирает комментарии и выделяет паттерны.

### Что анализируется:

#### 1. Структура
- Длина и количество слов
- Параграфы и предложения
- Пунктуация

#### 2. Стиль и тон
- Формальность/неформальность
- Эмоциональность
- Использование эмодзи

#### 3. Паттерны начала
- Согласие ("Согласен!", "Точно!")
- Вопросы
- Личный опыт ("У меня был...", "Я сталкивался...")
- Благодарность ("Спасибо!", "Благодарю!")

#### 4. Содержание
- Упоминание личного опыта
- Предоставление ценности (советы, инсайты)
- Использование сторителлинга
- Вопросы к аудитории

#### 5. AI детекция (обратные признаки)
- ⚠️ Шаблонные AI фразы ("стоит отметить", "в заключение")
- ⚠️ Слишком формальный язык
- ⚠️ Идеальная грамматика
- ⚠️ Повторяющаяся структура

### Пример кода:

```python
from analyzer import CommentAnalyzer

analyzer = CommentAnalyzer()

comments = [
    {'text': 'Согласен! У меня был похожий опыт 🚀'},
    {'text': 'Отличный пост! Попробую этот подход...'}
]

# Анализ
result = analyzer.analyze_multiple_comments(comments)

# Результаты
print("Рекомендации:", result['recommendations'])
print("Паттерны:", result['aggregate_patterns'])
```

### Результаты анализа:

Система выдает:
- 📊 **Метрики** (средняя длина, частота эмодзи и т.д.)
- 💡 **Рекомендации** для генерации
- 🎯 **Ключевые фразы** и паттерны
- ⚠️ **Признаки AI** для избегания

## Как отличить AI комментарий от человеческого

### 🤖 Признаки AI:

- Шаблонные фразы:
  - "it's worth noting" / "стоит отметить"
  - "furthermore", "moreover" / "более того"
  - "in conclusion" / "в заключение"
  - "dive deep", "delve into"

- Слишком формальный язык
- Идеальная грамматика
- Все предложения одинаковой длины
- Отсутствие личного опыта
- Нет эмоций

### 👤 Признаки человека:

- Разговорный язык и сленг
- Эмодзи 🔥✨💡
- Личный опыт ("у меня был...", "я сталкивался...")
- Неформальная пунктуация (..., !!, ??)
- Опечатки и повторы (круутоо)
- Эмоции и спонтанность
- Вопросы к аудитории

## Настройка под свою платформу

### LinkedIn

1. Создайте учетную запись
2. В .env укажите:
   ```
   PLATFORM=linkedin
   LINKEDIN_EMAIL=your_email

   ```
3. Запустите `python src/parser.py`

### Twitter/X

Потребуется Twitter API (Bearer Token):
```
PLATFORM=twitter

```

Расширьте `src/parser.py`, создав класс-наследник `SocialMediaParser`.

## Советы

### Для лучшего анализа (Step 2):
- Соберите минимум 30-50 комментариев
- Выбирайте комментарии с высоким engagement
- Анализируйте посты из вашей ниши

### Для лучшей генерации:
- Используйте высокую температуру (0.8-1.0)
- Делайте несколько попыток (max_attempts=3-5)
- Валидируйте через детектор
- Адаптируйте под свой стиль

### Безопасность:
- Не коммитьте .env с реальными ключами
- Используйте rate limiting для API
- Не автоматизируйте постинг без проверки

## Частые вопросы

**Q: Где взять API ключ для AI?**

A:
- Anthropic: https://console.anthropic.com/
- OpenAI: https://platform.openai.com/

**Q: Можно ли использовать без API ключа?**

A: Да! Анализ и детекция работают без API. Генерация требует ключ.

**Q: Как улучшить качество генерации?**

A:
1. Соберите больше примеров из вашей ниши
2. Настройте `config/patterns.json`
3. Увеличьте `max_attempts` в генераторе
4. Используйте референсные паттерны из анализа

**Q: Безопасно ли парсить LinkedIn?**

A: LinkedIn не приветствует автоматизацию. Используйте:
- С осторожностью
- Небольшие лимиты (10-20 постов)
- Задержки между запросами
- Или используйте официальное API
